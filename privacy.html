隱私權政策

龍馬文創科技股份有限公司（以下稱「我們」）
生效日期：2026-10-28　最後更新：2026-10-28

1. 這份政策適用於什麼

本政策說明「育兒社群聆聽分析平台」（以下稱「本工具」）如何處理來自 Threads 的資料。本工具是我們內部研究人員使用的資料蒐集與分析工具，用於育兒、親子、教養主題的研究，產出彙總統計與研究報告。本工具不對外開放註冊，一般大眾不會被要求登入或提供個人資料。

2. 我們蒐集哪些資料

2.1 研究人員授權的帳號資料

研究人員以自己的 Threads 帳號授權本工具後，我們會取得：

  • Threads 使用者編號與帳號名稱
  • 存取權杖（access token），用於呼叫 Threads API

這些資料只屬於授權的內部研究人員。

2.2 搜尋到的公開貼文

我們透過 Threads API 的關鍵字搜尋功能，依育兒相關關鍵字搜尋公開貼文，並只保存下列欄位：

欄位用途
貼文文字議題分類、質化閱讀與引用
發布時間劃分時間區間、標註引用時間
貼文連結回查原文、去重
貼文編號去重
貼文類型（文字、圖片等）篩選純文字貼文
是否為回覆、是否為引用貼文判斷貼文性質
發文者的公開帳號名稱避免同一人重複計算；不用於個別帳號分析，對外引用時不顯示，見第 5 節

2.3 我們不蒐集的資料

  • 私訊、非公開貼文或任何需要登入才看得到的內容
  • 大頭貼、真實姓名、電話、地址、電子郵件
  • 追蹤者與追蹤中名單
  • 讚數、留言數等互動數據
  • 圖片、影片檔案本身

3. 我們如何使用這些資料

  • 彙總統計： 將貼文依議題分類，計算各時間區間（例如每 30 天）的有效貼文數與議題占比，觀察議題的時間變化。統計只以議題與時間區間為單位呈現
  • 質化觀察： 閱讀貼文，挑選少量具代表性的內容，作為研究報告的引文或佐證
  • LLM 輔助分析： 使用大型語言模型（LLM）協助分類貼文、歸納主題、找出常見說法，以及協助整理報告。詳見第 8、9 節
  • 報告發布： 研究報告（含彙總數字與少量引文）可能公開發布，也可能以付費方式提供給企業或其他機構。我們提供的是自己整理的研究報告，不是原始貼文資料

4. 我們不會做的事

  • 不對個別使用者做追蹤、側寫或行為分析，彙總統計也不以個別帳號為單位
  • 不嘗試辨識或聯繫貼文作者
  • 不把 Threads 的關鍵字取樣數量當作整體討論量或全體家長的比例對外呈現；報告會註明 Threads 資料是依關鍵字取樣的公開貼文，不代表全體家長
  • 不出售、出租原始貼文資料或貼文資料集；研究報告只含彙總數字與少量去識別的引文。分享的例外情況見第 9 節
  • 不用於廣告投放或個人化推播
  • 不用這些資料訓練或微調任何模型

5. 對外引用貼文的方式

研究報告對外發布時，引用 Threads 貼文會遵守：

  • 只引用必要的片段，並標註平台（Threads）與發布日期
  • 不顯示發文者帳號名稱；引文中出現孩子的姓名、學校、照片等可識別資訊時，一律刪除或改寫
  • 不批次公開原始貼文資料集

6. 資料保存期限

  • 貼文文字與我們依其產生的議題分類標註，保存12個月，供跨期比較與重新分類使用；超過期限即刪除貼文文字
  • 刪除貼文文字後，只保留不含貼文文字、也不含帳號名稱的彙總統計（各期貼文數、議題占比）
  • 存取權杖在研究人員撤銷授權、或離開研究團隊時立即刪除

7. 貼文被刪除或改為非公開時

貼文作者在 Threads 刪除貼文，或改成非公開後，我們不應繼續保存其文字。

  • 每次使用資料前，我們會先重新檢查貼文連結是否仍公開，不再公開的就從資料集和草稿中移除
  • 已完成的彙總統計只含數字，不含貼文內容，不會因個別貼文被刪除而重算，但不再公開的貼文不會被用於新的統計
  • 已發布的報告中若引用了後來被作者刪除的貼文，我們收到通知後會在30日內修改或移除

8. 資料安全

  • 資料存放於研究人員自行管理的本機電腦，不上傳至雲端儲存或伺服器，不對外公開
  • 在本機執行的開源 LLM 分析時，資料不會離開該電腦
  • 存取權限僅限內部研究人員；存取權杖以環境變數保存，不寫入程式碼，也不放在公開位置
  • 傳送給雲端 LLM 服務的內容限於完成分析所需的貼文文字，不含發文者帳號名稱

9. 資料分享

我們不出售、出租原始貼文資料，也不與第三方分享，但下列情況除外。提供給購買者的研究報告只含彙總數字與少量去識別的引文，不屬於分享原始資料：

  • 雲端 LLM 服務供應商： 研究人員使用雲端 LLM 服務協助分析與整理報告時，會將完成分析所需的貼文文字傳送給該供應商處理。目前使用的供應商：Anthropic（Claude，公司的 Team 商業方案）。我們只使用依其條款不將我們輸入的內容用於模型訓練的方案或設定，並遵守其資料處理條款
  • 法律規定、法院命令或主管機關的要求

我們不使用雲端主機或雲端儲存來保存這些資料。資料來源 Threads API 由 Meta 提供，不在此限。如果日後新增其他服務供應商，我們會先更新本政策再開始使用。

10. 你的權利與刪除請求

如果你是 Threads 貼文作者，認為我們保存或引用了你的貼文，你可以：

  • 要求我們告訴你，我們是否保存了你的資料
  • 要求我們刪除你的貼文資料，並從尚未發布的內容中移除
  • 要求我們修改或移除已發布報告中的引用

如何提出： 寄信到 ai@realma.com，信中請附上貼文連結或你的 Threads 帳號名稱。我們會在14個工作日內回覆，在30日內完成處理。

11. 資料刪除說明（供 Meta 平台使用）

如果你曾授權本工具存取你的 Threads 帳號，要求刪除相關資料的方式：

  1. 在 Threads 或 Instagram 的設定中，移除本工具的存取權限
  2. 寄信到 ai@realma.com，主旨寫「資料刪除請求」，附上你的帳號名稱
  3. 我們會在30日內刪除你的帳號資料與存取權杖，並回信確認

12. 兒童

本工具不是給兒童使用的，也不會刻意蒐集 13 歲以下兒童的資料。研究主題是家長在公開貼文中描述育兒經驗，貼文可能提到孩子，我們不會保存或公開孩子的可識別個資，做法見第 5 節。

13. 政策修改

我們可能修改本政策。重大修改會在本頁更新「最後更新」日期，並在修改生效前提前 7 日公告。
